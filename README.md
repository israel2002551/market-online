# BUYSELL Nigeria 🇳

Nigeria's most trusted online marketplace for buying and selling authentic products with video listings.

## Features

- ✅ User Authentication (JWT)
- ✅ Product Listings with Video Support
- ✅ Advanced Search & Filters
- ✅ Secure Payments (Paystack/Flutterwave)
- ✅ Seller Verification System
- ✅ Buyer Protection
- ✅ Real-time Chat
- ✅ Mobile Responsive

## Tech Stack

**Frontend:**
- HTML5, Tailwind CSS, JavaScript
- Responsive Design

**Backend:**
- Node.js + Express
- MongoDB + Mongoose
- Cloudinary (Media Storage)
- JWT Authentication

## Installation

### Prerequisites
- Node.js (v16+)
- MongoDB
- Git

### Backend Setup

```bash
cd backend
npm install
cp .env.example .env
# Edit .env with your credentials
npm run dev
