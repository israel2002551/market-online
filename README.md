# BUYSELL Nigeria 🇳🇬

Nigeria's most trusted online marketplace for buying and selling authentic products with video listings.

## Features

- ✅ User Authentication (JWT)
- ✅ Product Listings with Video Support
- ✅ Advanced Search & Filters
- ✅ Secure Payments (Paystack/Flutterwave)
- ✅ Seller Verification System
- ✅ Buyer Protection
- ✅ Mobile Responsive Design

## Tech Stack

**Frontend:**
- HTML5, Tailwind CSS, JavaScript

**Backend:**
- Node.js + Express
- MongoDB + Mongoose
- Cloudinary (Media Storage)
- JWT Authentication
